# Betel Elevadores

Site estático em HTML, CSS e JavaScript. Para visualizar antes de publicar, abra o arquivo `index.html` no navegador.

## Publicar pelo GitHub Pages

1. Extraia o ZIP. Envie os arquivos extraídos para a raiz do repositório, com o `index.html` no mesmo nível do `README.md`.
2. No GitHub, abra **Settings → Pages**. Em **Source**, selecione **Deploy from a branch**.
3. Selecione o branch que contém os arquivos (por exemplo, `main`) e **/(root)**. Clique em **Save**.
4. Quando a publicação concluir, volte a **Settings → Pages** para ver o endereço do site.

O arquivo `.nojekyll` indica ao GitHub Pages que os arquivos já estão prontos para publicação. O formulário de orçamento abre uma conversa no WhatsApp da Betel com uma mensagem preenchida.

[Documentação oficial do GitHub Pages](https://docs.github.com/pt/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
